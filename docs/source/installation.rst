Installation
============

Requirements
------------

* Python >= 3.10
* JAX
* NumPy
* matplotlib
* jaxtyping
* chex
* optax
* equinox

Installation from Source
------------------------

.. code-block:: bash

   git clone https://github.com/tdinelli/diffPLOG2TROE
   cd diffPLOG2TROE
   pip install .

Development Installation
------------------------

For development, install with optional dependencies:

.. code-block:: bash

   pip install -e ".[dev]"
